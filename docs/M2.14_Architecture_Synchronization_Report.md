## 5. Changes made

**One file: `docs/architecture.md`.** 27 insertions, 7 deletions.

### 5.1 §5 — the component table

The single `Generator` row became **two rows**, carried in the existing column structure with **no new column added**: contract era is stated in the *Interface* cell, execution surface in the *Current Milestone* cell.

- **`Generator`** — v1.0.0, `generate(query, retrieval)`, deterministic / credential-free / network-free / byte-reproducible, executed by `scripts/cli.py`. *Future Evolution* is now **"None — preserved, not superseded"**, which is exactly the revisit the P3.7.4 note deferred to register **M2-14**, and it replaces the *"DeepSeek API integration"* forecast that RO-14 made false for this component.
- **`ModelGenerator`** — v2.0.0, `generate(prompt: Prompt)`, one sanctioned provider interaction, non-deterministic `answer_text` over structurally deterministic request/parse/evidence behaviour, executed by `scripts/run_generation.py`.
- **`CLI`** — dependency corrected from *"All of the above"* to *"Retriever, `Generator` — the Milestone 1A chain"*, verified against `scripts/cli.py`.
- **A new adjacent synchronization note** records the seven points above, the RO-13 D-5 relationship, the shared artifact types, and the deliberate non-changes. **The Sprint P3.7.4 note is byte-unchanged**; the new note sits beside it and does not restate it.

### 5.2 §2 — the interface-first principle

An adjacent disclosure note, following the same discipline §5 and §9 already use for their own divergences. It states plainly that **the principle is NOT satisfied between the two components**, that it continues to govern every other component, that **§10 is deliberately unchanged** because RO-14 satisfied its deliberate-decision requirement rather than revising it, and that **no abstraction, adapter, router or superclass is introduced**.

### 5.3 §8 — the sequence diagram

The diagram now carries `Generator` and `ModelGenerator` as separate participants and draws two paths:

```text
Milestone 1A:  Retriever -> Generator -> GenerationResult
Milestone 2:   Retriever -> Context Builder -> Prompt -> ModelGenerator -> GenerationResult
```

The Milestone 2 leg is `docs/GENERATION_CONTRACT.md` §24.2's pipeline, transcribed. A short paragraph beneath the diagram states that both paths exist concurrently and that neither replaces the other.

### 5.4 §9 — the Milestone 2 bullet

*"DeepSeek `Generator` implementation"* → *"DeepSeek `ModelGenerator` implementation — the Milestone 2 model-backed generation component, added **alongside** the frozen Milestone 1A `Generator` rather than replacing it (**RO-14**; §5)."*
