## 1. Milestone summary

Milestone 1A set one gating question, and answered it:

> **Can we deterministically trace every answer back to verified knowledge, without relying on any probabilistic AI component?**
>
> **Yes — by demonstration**, not by assertion. Every statement the pipeline emits carries a chunk id, a document id and document-frame character offsets, and each statement's text is byte-identical to its supporting span.

The milestone built an evaluation lab before the system it measures, and proved the lab deterministic before allowing anything probabilistic near it. What it delivered is recorded in the authorities cited in §3 and is **not restated here** — per Work Package 3, this document freezes by reference rather than by duplication.

**Milestone 1A closes with its Definition of Done annotated, not satisfied.** Five of seven items are met; two are annotated with the reason they are not. That distinction is the milestone's most important governance property and is preserved verbatim at `docs/MILESTONE_1A.md` — *Repository Owner Scope Ruling (P3.7.3)*.

### 7.1 One limitation the brief did not name, carried forward rather than dropped

**P3.7.5 finding F-2 — `manifest_version` remains `1.0` after a schema extension.** `docs/MILESTONE_1A.md` build item 1 states that *"`manifest_version` changes only when the Knowledge Manifest schema itself changes"*, and adding `canonical` is a schema change. It was not incremented because P3.7.5's own brief required preserving the existing schema, `validate_manifest` rejects any other value, and the contract freezing `1.0` is a governance document that sprint could not modify.

Work Package 5's enumeration did not include it. It is recorded here because a finding raised at P3.7.5 §8 and left unresolved would otherwise lapse silently at closure, and **CP-8** requires the gap be recorded rather than the statement softened. **This records an existing finding; it introduces no new work and reallocates nothing.** Resolution is a Repository Owner decision, available at any time and blocked by nothing.
